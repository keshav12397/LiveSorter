#
#   Calibration: skipCalibration, trainingKsDir, trainingBinPath,

#     calibrationWorkers, calibrationSeed, templateOffset.
#     calibrationScript defaults to FilterGen/calibrate_all_units.py here,
#     not calibrate_for_closedloop.py. There is no calibrationBackend=cpp

#   Fetch:    sglxHost, sglxPort, filterDir, templateLength,
#             filterNChannels, carChannelMapJson, applyHighpass,

#             latencyLogPath.
